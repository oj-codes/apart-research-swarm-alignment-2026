## One-line

`grite`, a server-less git-native coordination substrate that stores an append-only, content-addressed,
optionally signed event log inside git refs — and then mines that log for coordination failures
invisible to PR history.

## Why it's in the library

The closest thing to what this team is already doing: coordination state that travels with the code on
ordinary fetch and push. Its mined failure modes — conflicting edits, lock starvation, **redundant
rediscovery**, race-to-close — are named categories we can check ourselves against, and several are
unrecoverable from PR history because an abandoned duplicate never becomes a PR.

Releases an exporter and mining toolkit so others can run the identical detectors on their own agents,
and names that real-agent study (tier-T2) as future work.

**Careful with:** the headline 78%->0% duplicate-work result is from **deterministic seeded synthetic
agents on an abstract task pool — no LLMs, no real source files.** The author is scrupulous about this.
The transferable finding is the discriminating one: advisory leases *alone* don't prevent redundant
rediscovery; leases plus shared state do.
